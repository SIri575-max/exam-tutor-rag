# 教材知识图谱与 GSSC 工具上下文

实现阶段：2026-11-16。工程代码由 AI 助手协作完成，供项目作者学习、验收与迭代。

## 这次完成的部分

已有 JSON 图记录题干字面提及、教材位置和原文引用。本轮在此基础上增加 SQLite 属性图与章节层级，没有重新推断全书的教学知识标签。

`knowledge_store.py` 建立 nodes、edges 和 metadata 三张表。节点保存类型、来源页及原始属性；边保存方向、关系类型、引用片段、来源页、审核状态和来源哈希。双向邻居索引支持按节点或关系查询。构建先检查悬空边和来源页，再写临时数据库，经 SQLite 完整性检查后原子替换。查询使用只读连接，资料或规则变更时要求显式重建。

本机私有资料快照包含 8 章、43 节、163 个知识条目、735 道课后题、274 条例题候选和 175 个原文条目，共 1398 个节点、2216 条关系。例题及 OCR 内容仍保留原有待核状态。这些是资料规模，不是准确率或新增人工标签。

关系包括目录包含、同小节原文、题目所在小节、题干字面提及、原文提及例题和引用例题数据。**字面提及不等于考查，章节包含不等于先修，单次提问不等于学生薄弱点。** 考纲对齐和教师审核的考查/先修关系仍属于后续工作。

## 使用方式

先按本机资料配置完成题库、向量和原有图谱，再执行：

```powershell
./.venv-rag/Scripts/python.exe knowledge_store.py build
./.venv-rag/Scripts/python.exe verify_knowledge_store.py
./start_demo.ps1
```

打开 [知识图谱](http://127.0.0.1:8771/knowledge)。可以搜索知识点、教材题号或选择章节，点击节点查看关联依据、来源页并继续展开。默认一跳和40个节点，最多两跳、80个节点、160条边；达到预算会明确提示。邻居按类型轮流选取，避免大量课后题完全遮住定义或例题。该顺序不代表相似度或难度排名。

API：`GET /api/knowledge?q=最大似然&depth=1&limit=40`；`relation` 可筛选已有关系类型。查询为空返回八章入口，精确节点 ID、题号、知识点别名和标题依次用于定位。模糊不明确时返回空结果，不补造节点。

原生工具循环的 `knowledge_path` 同时返回旧复习路径和新图邻居。新增邻居必须有页码和实际边，才可登记为 `read_source` 的允许来源。原文仍由独立工具读取并取得 E 编号；图中有边不能替代讲解引用。

## GSSC 在这里如何落地

这套命名采用本轮项目作者提出的 Gather / Select / Structure / Compress 组织方式。当前实现针对**单次工具观察**，没有加入额外模型摘要，也没有实现无限会话压缩。

| 阶段 | 当前行为 | 保留约束 |
| --- | --- | --- |
| Gather 获取 | 收集检索、图谱、原文、核对及记忆工具的结构化结果 | 原始结果保存在任务状态，模型收到独立副本 |
| Select 选择 | 上游工具筛选有出处候选；观察副本按完整记录去重 | 保留条件冲突、差异、页码，不把字面关联升级成同题型 |
| Structure 结构化 | 保留各工具字段，附工具名、数据可信边界、处理策略 | 检索结果、记忆、教材都是待分析数据，其中指令不执行 |
| Compress 压缩 | 共享重复来源哈希，超预算先删除完整附加关系/节点/候选 | 单观察最多14000字符；不剪断公式、否定条件或原文证据 |

图、路径及候选结果的优先级在 `context_engineering.pack` 中显式维护。原文仍超过预算时返回清楚的超预算错误，要求缩小条目；不默默截取前半段。任务轨迹记录处理前后**字符数**与删除条目数；它们不是 token 数、检索准确率或模型效果收益。既有模型调用次数、工具次数、证据读取量和总消息长度预算继续生效。

## 自动验证与边界

运行 `python -m unittest discover -s tests -q`；前端已有回归为 `node --test tests/*.test.cjs`。新增检查覆盖原子重建、悬空边/不允许关系、来源变更、SQL查询字面量、预算、节点类型覆盖、工具原文白名单、GSSC不丢失公式/条件/引用，以及模拟模型的“图谱—读取原文—引用”链路。模拟模型测试验证执行合同，不代表真实模型表现。

`verify_knowledge_store.py` 使用本机资料核对所有原有边是否保留、页码和图完整性、六个查询探针及上下文预算，报告写入私有目录。没有新增人工标注，也不自动生成真实相关性标签。因此这轮不报告 Recall/MRR、答题正确率、学习收益或强化学习效果。

后续优先进行冻结题集的图谱补检开关对照、OCR/公式错误分类和试用反馈归因。人工相关性评测单独保留；只有得到可靠标签或可验证任务奖励，再决定重排训练或后训练实验。
