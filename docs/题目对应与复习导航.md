# 新题对应例题、课后题与知识点

更新：2026-11-04。首要目标：学生上传或输入一道题，定位茆书相关例题、课后题和知识点，说明关联依据与条件差异，帮助选择回看章节和后续练习。生成完整解答作为可选辅助。

## 本轮实现

1. 结果顶部直接给出知识点、先看例题、再练课后题；知识点和每条推荐均可打开教材原页。
2. 检索保留混合召回，公式排名只作有界加权。结构包含明确分布、多个运算和条件时给予较高权重，通用公式使用较低权重；这些权重是开发默认值，尚非最优参数。
3. 公式候选按例题、课后题分别组织，避免一类题占满全局候选。按任务相关性、显式分布与运算线索组织练习，不把两类题的“都有结果”当成相关性正确。
4. 推荐说明区分所求任务相关、结构相关、所求量待核对、条件不同、语义候选和多分布汇总背景。显式条件不一致、样本量未识别和例题摘要不全均提示核对。
5. 修正负二项分布与Beta名称同时出现就误判Beta先验的规则；必须有“先验/共轭”文字依据。
6. 知识点线索区分题干任务、明确提及、公式运算、分布和候选原文。附复习自查问题，不据题目自动断定学生薄弱点。

本轮不改原始教材OCR、向量索引、历史冻结报告或人工标签。仍使用现有本地BGE与BM25；没有新模型下载或付费生成请求。

## 可复现示例

启动 `python app.py --port 8771`，打开 `http://127.0.0.1:8771/problems`，点击“最值与无偏估计”。

- 课后题首项：习题6.1第6题，教材PDF294页。
- 例题首项：例6.1.6，教材PDF293页。
- 知识点线索：点估计及无偏性、有效性、方差、次序统计量及均匀分布。
- 条件核对：原例使用一般样本量，输入为3个样本；部分摘要未完整标明所需方差内容。推荐不等于可直接套用结论。

上传题图仍走原有OCR、人工核对后查题入口；本轮浏览器验收使用上述文字/公式输入，没有重新开展OCR准确率评测。

## 验证与限制

- 240项后端检查及11组前端检查通过。
- `python evaluate_correspondence.py`：6条已查看公式开发变体的出处均首位定位；9条已查看外部出处开发样本亦均首位定位。此前两组已分别达到6/6和9/9，本轮是保留已有出处能力，不宣称新增独立准确率收益。
- 6条公式输入均返回两类练习；此项仅检查流程覆盖，未对全部推荐进行教师相关性评分。
- 浏览器实际核查知识点、例题/课后题推荐、条件说明、公式显示、复习自查和知识点原页打开；无水平溢出。

开发报告另存 `data/private/correspondence-20261104/run-*/report.json`。初次降低公式权重导致开发出处变体退化的记录保留在 `initial-development-probes.json`；后续融合及类型内排序根据已查看样本调整，不能将这些样本作为独立测试。
