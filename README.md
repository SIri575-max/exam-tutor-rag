# 知题 · 统计学查题与复习助手

知题帮助学习者用文字或题图定位相关教材例题、课后题和知识点。系统在本机处理资料，展示命中片段、条件差异和来源页。660B 素材库提供题干核对与查题入口，人工核对页用于记录教材题的相关性。

## 功能与实现

- **分块与检索**：保留完整题目作为父记录。较长题干切成保护常见数学结构的子片段，命中后回到完整题目。结合 BM25、BGE 向量检索和 RRF 排名融合。
- **相关题推荐**：用分布、公式结构和所求量补充候选，再分别推荐例题与课后题。
- **题图识别**：本地 OCR 后在查题框核对公式和题干，再手动检索。
- **可选讲解**：通过配置的模型服务生成带来源编号的讲解。使用者在界面上明确启用后提交。
- **离线评估**：分别报告已知出处定位和人工标注的相关性。对照口径与分块参数见[召回与评估指南](docs/召回TopK与评估指南.md)。

## 快速验证

Python 3.12 下可以先跑仓库自带的小样例，验证题目召回和评估计算。小样例使用自编题干，运行时只需 Python 标准库。

```powershell
python examples/retrieval_demo.py
python -m unittest discover -s tests -p "test_retrieval_metrics.py"
```

## 本地工作台

在 Windows PowerShell 中创建检索环境，再启动应用。

```powershell
py -3.12 -m venv .venv-rag
& ./.venv-rag/Scripts/python.exe -m pip install -r requirements-retrieval.txt
./start_demo.ps1
```

在本机打开 [查题工作台](http://127.0.0.1:8771/problems)。完整检索、原页、OCR 和历史评估页面需要本机资料及其生成文件。克隆后先用上面的小样例了解流程，再按[本机资料配置](docs/local-setup.md)准备数据。

仓库包含代码、配置模板和小样例。教材、讲义、660B 题干、题图、答案、向量库、审核记录、模型权重和密钥由使用者在本机管理。KaTeX 的许可证随资源一起保留。
