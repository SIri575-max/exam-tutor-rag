## 题干抽检和反馈训练（2026-11-05）

本机抽检页位于 `data/private/660b-evaluation/recognition-review-20261105/抽检.html`。八章各固定抽 3 道待选题，并另列 6 道重点复核题。对照原页选择核对结论，可填写正确公式、符号、选项或遗漏条件，最后下载 JSON。抽检样本含刻意选取的疑难题，分章样本的结果与重点样本分别记录。

575 道题均完成题号、OCR 片段和 82 张题目页图的来源一致性检查，其中 47 道跨页。以 300 DPI 重识别 PDF 第 6、7、8、12、28、29、43、65 页后，64 道题可按同题号同页范围配对。57 道有文本差异，含排版变化。同 64 道题两版检测到的公式分别为 151 和 148 个，编译失败由 2 处变为 0 处。两次识别在补事件、分母和求和上下限上仍有错漏，因此另按原页补录 3 道，供用户确认。自动结果和补录建议均在独立抽检归档。

抽检可形成「题图 → 核准转录」的 OCR 监督样本。要训练教材题排序，使用人工核对页给候选题标 0–3 级，并记录题族。先用这些标签训练成对排序，保持同题变式同组划分，在冻结测试集按例题与课后题分别比较前 3 条结果。若后续收集到足量的交互反馈，可以将选择检索策略或 Top K 建成上下文赌博机，用人工确认的命中和额外等待成本定义奖励，记录展示顺序和策略选择概率。点击反馈会受到位置影响，需要与显式相关性标签区分。当前阶段已准备抽检和标注入口，模型训练待标签积累。 [RankNet 原论文](https://www.microsoft.com/en-us/research/publication/learning-to-rank-using-gradient-descent/) · [点击偏差与排序学习](https://arxiv.org/abs/1608.04468)

## 一次性批处理

1. `python external_question_bank.py`：146页本地OCR，保存指纹、逐页原始输出及断点。
2. `python complete_external_evaluation.py --wait-for-ocr`：等待该批次完整完成，切题并运行四种检索，生成审核表和研究记录。不调用付费模型。

已有OCR进程运行时，不要重复启动第1步。第2步的状态在 `completion-status.json`。有错页时停止冻结；正常完成状态为 `complete_pending_teacher_review`。

`660B`是资料名，实际题量由逐章题号和切分核对确定。已对照原页确认题干PDF6–87、答案PDF88–146和八章首页。部分题没有星级、同一OCR块含两题或跨页选项；原始输出不改，人工切分补注带原文哈希，变化后拒绝复用。

本批146页OCR已完成，识别575道主编号候选：八章依次90、80、98、33、70、111、63、30道，题号无缺号/重号；不表示全部内容识别正确。1道含图题暂缓，其余574道完成四组共2296次本地检索。全量相关性标签仍为空；参考答案59页封存在独立文件，未自动生成逐题正确答案标签。

## 防止评测混用

- 660B不写入教材向量库；参考答案单独封存，不进入查询或提示词。
- 原始OCR与人工核对版分别评价。拍照变体、小问和同题参数变式共用题族，题族审核前不分入保留测试集。
- 同题出处定位、新题相关方法检索、最终解答、格式稳定性和引用支持分别统计。
- `source-anchor-labels.json`是9个助手核对的出处锚点，属于便利开发样本，含教材重复题，非新题准确率。标签在查看对应排序前保存，但批量检索已启动，不能称为前瞻独立测试。
- 全量候选检索只生成盲评池；无相关性标签时Recall/NDCG保持null。填写审核人、题族、重合分层、全部池内0–3等级后，才可导入评分。Recall/NDCG使用已判断的候选池，不是全语料穷尽标注。
